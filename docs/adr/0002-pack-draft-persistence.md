# Auto-persist the in-progress Pack Draft, separately from Partner Art History

Building on [ADR-0001](./0001-indexeddb-for-partner-art-history.md), we extended the same IndexedDB database with a second object store holding the whole in-progress pack (name, version, skins, Store Images gallery, Key Art/Marketing Art), debounce-saved on every change so a refresh or crash doesn't lose work. Partner Art was deliberately left out of this record and continues to be restored via Partner Art History's own MRU mechanism: Partner Art is a reusable asset a user picks up across many packs, not state that belongs to one in-progress pack, so folding it into the Pack Draft would make "Start New Pack" either wipe a reusable asset or need special-casing to skip one field. Because refreshing the page used to be the only way to reset the form, adding always-on persistence removes that implicit reset — a "Start New Pack" action was added alongside it to clear the Pack Draft (Partner Art untouched).
